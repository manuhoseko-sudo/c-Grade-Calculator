Student Grade Calculator (C)

A simple, beginner-friendly C program that takes a numeric score (0-100) and outputs the corresponding letter grade (A, B, C, D, F). This project demonstrates core programming concepts like conditional logic, user input, and data validation.

Features

· Accepts numeric input from the user.
· Validates input to ensure it is between 0 and 100.
· Uses if/else statements to determine the grade.
· Prints the final grade clearly to the console.

How to Compile and Run

To compile and run this program, you will need a C compiler (like GCC).

1. Compile the code:
   gcc grade_calculator.c -o grade
2. Run the program:
   ./grade
